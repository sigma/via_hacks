# EK21 as a Dirtywave M8 controller

Keymap: `keyboards/ek21.jsonnet` — build with `just via-ek21`.

M8 buttons on a keyboard: **SHIFT** = Left Shift, **PLAY** = Space,
**OPTION** = `Z`, **EDIT** = `X`, directions = arrow keys.

Every layer shares the same frame: the key next to the knob **holds** the FN
layer, the tall key on the right is **EDIT**, and the bottom row is
**SHIFT / PLAY / OPTION**. The FN layer's bottom-left row switches layers.

## Layer 0 — EDIT

```
+----------+----------+----------+----------+
| STOP ALL |    FN    |  SELECT  |   COPY   |   knob: value -1 / +1
+----------+----------+----------+----------+
|  NEW ID  |  CLONE   |  PASTE   | CUT/DEL  |
+----------+----------+----------+----------+
|  PG UP   |    UP    |  PG DN   |          |
+----------+----------+----------+   EDIT   |
|   LEFT   |   DOWN   |  RIGHT   |          |
+----------+----------+----------+----------+
|  VIEW <  |  VIEW >  |   HELP   |          |
+----------+----------+----------+  OPTION  |
|        SHIFT        |   PLAY   |          |
+---------------------+----------+----------+
```

| Key      | M8 combo               | Does                                         |
| :-------- | :---------------------- | :-------------------------------------------- |
| STOP ALL | SHIFT+PLAY             | Play / stop all tracks (toggle)              |
| SELECT   | SHIFT+OPTION           | Toggle selection mode                        |
| COPY     | OPTION                 | Copy selection (in selection mode)           |
| NEW ID   | EDIT, EDIT             | Insert next unused chain / phrase / instr.   |
| CLONE    | SHIFT+[OPTION, EDIT]   | Copy current item into a new slot            |
| PASTE    | SHIFT+EDIT             | Paste copy buffer                            |
| CUT/DEL  | EDIT+OPTION            | Clear value / cut selection / note-off       |
| PG UP/DN | OPTION+UP/DOWN         | Song: 16 rows. Phrase: prev/next phrase      |
| VIEW </> | SHIFT+LEFT/RIGHT       | Song ↔ Chain ↔ Phrase ↔ Instrument ↔ Table   |
| HELP     | EDIT+UP                | On a command column: FX help / selection     |
| knob     | EDIT+LEFT / EDIT+RIGHT | Value −1 / +1 (EDIT+UP/DOWN by hand = ±16)  |

## Layer 1 — LIVE

```
+----------+----------+----------+----------+
| STOP ALL |    FN    |   MUTE   |   SOLO   |   knob: cursor up / down
+----------+----------+----------+----------+
| CLR M/S  |   CUE    |  SOLO <  |  SOLO >  |
+----------+----------+----------+----------+
|  PG UP   |    UP    |  PG DN   |          |
+----------+----------+----------+   EDIT   |
|   LEFT   |   DOWN   |  RIGHT   |          |
+----------+----------+----------+----------+
|  VIEW <  |  VIEW >  |  VIEW v  |          |
+----------+----------+----------+  OPTION  |
|        SHIFT        |   PLAY   |          |
+---------------------+----------+----------+
```

| Key      | M8 combo            | Does                                             |
| :-------- | :------------------- | :------------------------------------------------ |
| MUTE     | OPTION+SHIFT        | Mute current track (held: OPTION released first) |
| SOLO     | OPTION+PLAY         | Solo current track (held: OPTION released first) |
| CLR M/S  | OPTION+SHIFT+PLAY   | Clear all mutes and solos                        |
| CUE      | LEFT+PLAY           | Song: cue the selected row for playback          |
| SOLO </> | OPTION+LEFT/RIGHT   | Song: solo all tracks left / right of cursor     |
| VIEW <   | SHIFT+LEFT          | From Song view: enter / exit live mode           |
| VIEW v   | SHIFT+DOWN          | Down a view (e.g. Song → Mixer)                  |
| knob     | UP / DOWN           | Move the cursor through rows                     |

## Layer 2 — NOTES

```
+----------+----------+----------+----------+
| KEYJAZZ  |    FN    |  OCT -   |  OCT +   |   knob: octave down / up
+----------+----------+----------+----------+
|    A     |    A#    |    B     |    C'    |
+----------+----------+----------+----------+
|    F#    |    G     |    G#    |          |
+----------+----------+----------+   EDIT   |
|    D#    |    E     |    F     |          |
+----------+----------+----------+----------+
|    C     |    C#    |    D     |          |
+----------+----------+----------+  OPTION  |
|        SHIFT        |   PLAY   |          |
+---------------------+----------+----------+
```

One chromatic octave, C at bottom-left, reading left → right then up. Keys
send the m8c "keyjazz" letters (`Z S X D C V G B H N J M ,`); KEYJAZZ = `Esc`,
OCT −/+ = numpad `/` `*`. Notes play through the selected instrument and, with
the sequencer stopped on a note cell, are written into it.

## Layer 3 — FN (hold)

```
+----------+----------+----------+----------+
| STOP ALL |   (FN)   | RGB TOG  | RGB MOD  |   knob: RGB brightness
+----------+----------+----------+----------+
|  BLE 1   |  BLE 2   |  BLE 3   |   2.4G   |
+----------+----------+----------+----------+
|   USB    |   BATT   | CLR M/S  |          |
+----------+----------+----------+   EDIT   |
|          |          |          |          |
+----------+----------+----------+----------+
| → EDIT   |  → LIVE  | → NOTES  |          |
+----------+----------+----------+  OPTION  |
|        SHIFT        |   PLAY   |          |
+---------------------+----------+----------+
```

Hold FN and tap the bottom-left row to switch layer. BLE 1–3 / 2.4G / USB
select the host connection; BATT shows battery level.

## Notes

- M8 has no dedicated stop: STOP ALL is SHIFT+PLAY, which *starts* all tracks
  when stopped.
- Combos with SHIFT are real modifier chords and honour how long you hold
  them. Combos involving OPTION / EDIT / PLAY are VIA macros: a fixed
  press-release sequence, so you cannot hold them.
